# Три демонстрационные автоматизации — Idea to Action

Самостоятельные проекты для портфолио, не клиентские кейсы. Все входные данные синтетические. Внешние сервисы не подключены.

## Запуск

Python 3.10+ без дополнительных библиотек: `python run.py`.
Входные файлы находятся в data, результаты — в results.

1. Объединение прайсов: нормализация SKU и пробелов, проверка цены, выбор минимальной цены поставщика. 12 строк из 3 файлов → 8 товаров, 2 повтора объединены, 2 ошибочные строки вынесены отдельно. Цены обрабатываются через Decimal.
2. Обработка заявок: локальное воспроизведение событий в формате Telegram, проверка полей, запись в SQLite, экспорт CSV. 5 событий → 3 заявки, 1 повтор пропущен, 1 неполная заявка отклонена. Формат сообщения: имя | контакт | задача. Это не подключённый Telegram-бот и не интеграция Google Sheets. Для реального использования нужны API-адаптеры, доступы, согласованный сценарий и проверка доставки уведомлений.
3. Отчёт продаж: проверка количества и цены, группировка по товарам, ранжирование по выручке. 12 строк → 10 приняты, 50 единиц, выручка 130900 RUB, лидер Monitor. Две некорректные строки записаны отдельно. Возвраты и расходы в модели не учитываются, выручка не является прибылью.

При повторном запуске заявки не дублируются: SQLite хранит уникальный update_id. Метрика newly_saved станет 0. Остальные отчёты пересоздаются. Для чистого теста используйте новую копию каталога без файла results/enquiries.sqlite.

Карточки PNG визуализируют фактический summary.json, это не скриншоты внешних сервисов. Для их повторного создания нужен Pillow: `python package.py`. Этот скрипт также проверяет контрольные результаты и собирает ZIP.

Не измерялись: экономия времени сотрудников, результаты реального бизнеса, работа под нагрузкой. Демо не следует представлять как внедрения у клиентов.
